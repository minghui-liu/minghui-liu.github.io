Opening paragraph: introduce the question, observation, or argument. Use strong emphasis sparingly, italics for terms or titles, and descriptive link text instead of a raw URL.

Section heading

Develop the central idea with evidence, examples, and enough context for a reader outside the immediate project.

Subsection heading

Use an <h3> only beneath an <h2>. Inline code, variable names, filenames, and commands belong in <code>.

Lists

Use an unordered list when sequence does not matter:

  • First supporting point.
  • Second supporting point.
  • Third supporting point.

Use an ordered list for a procedure, ranking, or progression:

  1. Define the setup.
  2. Describe the method.
  3. Interpret the result.

Quotation or emphasized claim

A normal blockquote highlights a quotation or an important claim. Include attribution in the surrounding prose when appropriate.

Figure with caption

This paragraph wraps around the left side of the floated figure on desktop. Introduce what the reader should notice instead of relying on the caption alone.

Additional prose continues wrapping until it extends below the figure or reaches an element that clears the float.

Table

Wrap tables so they remain horizontally scrollable on narrow screens. Always include column headings.

Mathematics

Inline math stays within a sentence: the objective \(L(\theta)\) depends on parameters \(\theta\).

Display important equations in a scrollable math block:

\[ L(\theta) = \frac{1}{N} \sum_{i=1}^{N} \ell(f_\theta(x_i), y_i). \]

Define every symbol and explain what the equation means after displaying it.

Code

Use a language class such as language-python, language-javascript, or language-bibtex. Escape HTML characters inside code as &lt;, &gt;, and &amp;.

def mean_loss(losses):
    """Return the mean of a non-empty loss sequence."""
    if not losses:
        raise ValueError("losses must not be empty")
    return sum(losses) / len(losses)

Takeaway

Close with the main conclusion, practical implications, and any open questions. Avoid introducing a major new argument in the final paragraph.
